# MEGA favicon extraction

Mode: built-in image generation, edit of the v5 wordmark. Output: `mega-icon-v6.png`, a transparent 1254 × 1254 PNG. Modern browsers downsample this source for the tab icon; the same image is linked as an Apple touch icon.

## Prompt

Use case: background-extraction / precise-object-edit.
Asset type: transparent square browser favicon for the MEGA academic project.
Input image 1 is the edit target, the existing transparent MEGA logo. Extract ONLY the left evolution-stone emblem (the tall faceted blue-violet iridescent gem with the cyan/gold double helix and M-shaped ribbons). Remove all MEGA lettering and the long underline. Keep the emblem's identity, colors, faceted silhouette, and internal energy spiral faithful to the source. Do not redesign it or add any extra objects.
Center this one emblem in a square transparent canvas. Fit the full emblem, no cropping, approximately 90% of the height, with equal clear margins. Retain strong readable outlines and a clean alpha edge suitable for browser-tab display at 16–32 pixels. No letters, text, labels, wordmarks, tails from the wordmark, watermarks, background panels, shadows outside the emblem, or extra embellishments. Genuinely transparent background.
